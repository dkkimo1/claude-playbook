# Claude playbook

An open, six-step playbook for getting Claude into everyday use in companies of 5 to 80 people. Danish and English.

Live: https://dkkimo1.github.io/claude-playbook/ (Danish) and https://dkkimo1.github.io/claude-playbook/en/ (English).

Published by [Brinvik](https://brinvik.com), Copenhagen. Text and images are CC BY 4.0, see LICENSE.

`build/` holds the scripts that generate the pages and the images, so every claim and every label can be traced and rebuilt. Spotted something wrong or out of date? Open an issue.
