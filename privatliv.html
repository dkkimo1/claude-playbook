Privatlivspolitik

Siden udgives af Brinvik, København.

Hvad indsamler siden?

Siden indsamler ikke selv noget. Den har ingen formularer, ingen cookies, ingen analyse og ingen sporing. Værten kan dog logge IP-adresser (se nedenfor).

Hvem hoster siden?

Siden hostes af GitHub Pages (GitHub, Inc., USA). GitHub kan registrere besøgendes IP-adresse af sikkerhedshensyn. Data kan derfor blive behandlet uden for EU under GitHubs egne vilkår og databeskyttelsesrammen mellem EU og USA.

Kontakt

Har du spørgsmål om privatliv, kan du skrive via kontaktsiden på brinvik.com.
